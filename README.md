Tiger
===============

## Based On...

[*Modern Compiler Implementation in ML*](https://www.cs.princeton.edu/~appel/modern/) by Andrew W. Appel.

This is a Haskell-based implementation of the Tiger (toy) programming language, with the goal of being fully compliant with the author's test suite.

**For now, this implementation is wildly incomplete.**

[![Tiger CI](https://github.com/TheBizzle/Tiger/actions/workflows/tiger.yaml/badge.svg)](https://github.com/TheBizzle/Tiger/actions/workflows/tiger.yaml/badge.svg)

## Running

```sh
stack build && stack exec tiger
```

## Testing

```sh
stack test
```
